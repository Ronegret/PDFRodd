# PDF Rodd

Free online PDF editor that runs entirely in the browser — edit, sign,
highlight, annotate and compress PDFs with no install and no upload to a server.

🌐 **Live:** [rodrigonegrete.es/pdf-rodd](https://rodrigonegrete.es/pdf-rodd/)

## ✨ Features
- Edit & annotate PDFs (text, highlight, draw)
- Sign documents
- Compress PDFs
- 100% client-side — your files never leave your browser

## 🛠️ Tech
Vanilla `HTML/JS` · `pdf.js` · `pdf-lib` · `Fabric.js` · `Tailwind` (CDN)

## 🚀 Run locally
Open `index.html` in a browser, or:
```bash
python -m http.server 8080
```
