## 🧭 Overview
A free online PDF editor that runs entirely in the browser — edit, sign, highlight, annotate and compress PDFs with no install and no upload to a server.

## ✨ Features
- Edit & annotate PDFs (text, highlight, draw)
- Sign documents
- Compress PDFs
- 100% client-side — files never leave the browser

## 🛠️ Built with
`pdf.js` · `pdf-lib` · `Fabric.js` · `Tailwind`

## 🚀 Run locally
```bash
# open index.html
```
